# AI Flow Guide

Guided assistant that builds a work profile and produces an AI adoption report.

## Features

- Profile builder
- Work-context questionnaire
- Generated report and implementation guide

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Framer Motion

## Getting Started

```bash
git clone https://github.com/ghostland-dev/ai-flow-guide.git
cd ai-flow-guide
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
